# QuickForm版本更新记录

每一次版本升级，都来自我们对人工智能赋能教育的理解，来自我们对一线教师需求的回应。

## 版本说明

QuickForm分为两个版本，其中教师版为开源软件，适用安装在普通教师自己的电脑上，供上课快速使用；校园版为免费软件，适合一个区域（学校或者县域）多人一起使用。
