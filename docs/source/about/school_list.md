# 校园版合作单位

QuickForm在线版只能用于学习研究，难以承担真正上课使用。为此，我们开源了教师版（单用户），可以安装在教师的个人电脑上。考虑到种种原因，多用户版（即校园版）目前只免费提供给项目合作校（单位）。

考虑到快递寄送比较麻烦，我们正在寻求一种更加便捷的方式进行签约。如有好主意，请告诉。
