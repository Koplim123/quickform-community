# QuickForm规划

本来我们并没有什么规划，但是因为喜欢QuickForm的老师太多了，那就不能辜负大家的厚爱。

我们接下来准备做好这几个工作。

## 维护QuickForm官方网站

让更多教师用上QuickForm，首先需要将QuickForm部署在互联网上。QuickForm的官方网站支持大规模的用户，即校园版的QuickForm。

目前我们已经申请了独立域名，购买了云服务器。经费来源是我和方建文博士的科研经费。实际上也花不了很多钱，目前核心付出是精力。

新地址：[https://quickform.cn](https://quickform.cn)

我们计划将QuickForm接入各地的智慧教育平台。如果一切顺利，第一个接入的将会是上海的“三个助手”平台。

## 做好QuickForm的开源工作

QuickForm的教师版已经开源，目前已经实现了“内置环境，解压可用”。我们会做好教师版的维护工作，确保其不同操作系统的稳定运行。

毕竟我们不是企业，没有把握做到让QuickForm网站能同时服务很多人。最稳定可靠的做法是，让更多教师能自行部署和维护QuickForm。我们期望QuickForm能唤醒教师们驾驭AI编程（氛围编程）的意识，如同一颗火种。


## 做好AI赋能教学的培训工作

AI是工具，但不是一般的工具，是一个能创造新工具的工具。AI赋能教育教学，不是购买某个企业的什么系统就完事了。

我们期望让更多教师通过QuickForm深度认识AI。只有掌握了AI编程，才能真正理解AI的意义。不要给自己的人生设限，不要划分什么文科理科，有了AI，决定你的成长空间在于你的“心”有多大。


## 问与答

1.QuickForm开源吗？

QuickForm分为两个版本，教师版开源，校园版不开源。


2.QuickForm校园版为什么不开源？

QuickForm校园版在网络上服务，基于安全考虑，我们不能完全开放源码。如果需要，大家完全可以基于教师版增加功能。或者和我们签署合作协议，不用付费，只要确保不将源码扩散出去。


3.QuickForm官方网站会收费吗？

我们没有收费的意愿和渠道。但是有领导期望我们能收费，收很低的费用。如果QuickForm收费了，那一定是说明QuickForm遇到了瓶颈，需要借助外部力量的介入。如需要一定的经费来寻求更加专业的程序员来支持。

4.我们需要培训，能支持吗？

对于项目合作的单位，我们本来就要提供有偿的培训服务。相对来说，温州大学方建文老师的团队时间比较灵活，可以承担AI赋能教学方面的培训。
