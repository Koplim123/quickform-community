## HTML入门

1.HTML的标签

HTML（超文本标记语言）是网页的骨架，它使用标签来定义网页的结构。

基础HTML结构：

```
html
<!DOCTYPE html>
<html>
<head>
    <title>我的第一个网页</title>
</head>
<body>
    <h1>欢迎来到我的网页</h1>
    <p>这是我的第一个段落。</p>
</body>
</html>

```

常用HTML标签：

<h1>到<h6>：标题标签

<p>：段落标签

<a href="...">：链接标签

<img src="..." alt="...">：图片标签

<div>和<span>：容器标签
