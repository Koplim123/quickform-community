# QuickForm：教师版

## 功能演示

https://wzkjgz.site/quickform/

同校园版比较，教师版适合在本地电脑（任何电脑）上运行。

## 如何本地部署

感谢广西的伍老师写了一个教程。
https://mp.weixin.qq.com/s/phkIxGv7In4M6ogfHOMq1w

## 默认密码

内置了一个管理员账号：wst，密码：quickform

运行“update_wst_password.py”，可以初始化密码。，运行后关闭即可。
